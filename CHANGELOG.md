# Changelog

All notable changes to the Prasad Glass design system and this repo.
Versions follow semver: **major** = breaking (renamed/removed component, token or prop), **minor** = new component/token/variant,
**patch** = fixes and docs. Each Figma library publish uses the same version in its publish note.

## [Unreleased]

### Added
- Repo scaffold: `CLAUDE.md`, rules (`.claude/rules/`), designer README, Figma map, component index.
- Token export (DTCG) of all 456 variables, 98 text styles and 13 effect styles, with count verification.

### Added (docs, Stage 2)
- Foundations: colors, typography, spacing-radius, elevation (token tables generated by `scripts/render-docs.py`), icons, light-dark.
- 21 component docs (31 component sets) with AUTO blocks generated from the real Figma bindings (`scripts/figma/inspect-components.js`).
- Patterns: screen anatomy, navigation, forms, lists & cards, onboarding/KYC, overlays. Reference-screen map. Process: PRD template, PRD → screens, new component, governance. Voice placeholder.

### Changed (Figma, 2026-10-16)
- `font/size/body-md` 13 → **14** in Mobile and Tablet (line height stays 18), so body-md is now "compact body" 14/18 next to body-lg 14/20.
- New text style `mono/Regular` (JetBrains Mono 11/14, bound to `font/family/mono` and the caption size/line-height tokens) for documentation labels.
- 1,784 unstyled 10px JetBrains Mono labels in the DS doc frames are now bound to `mono/Regular` (11px). No overflow found.

### Decided
- Type scale: even sizes with an 11 minimum. `display-lg` (28) and `display-sm` (20) stay; `caps-sm` (10) stays only as a dense-badge exception.
- Desktop typography (15/13 values) is left until a Desktop product is in scope.

### Known issues (DS file)
- Reference-frame notes in Figma disagree with component bindings on 12 components (see "Figma doc drift" in each doc).
- Unbound values: OTP Input helper text (unstyled), Step radius 999, Timeline paddings and connector radius.
- Set defaults: Button / Icon Button default to Neutral · xs, TextField to sm.
- App Header page sits after ARCHIVE in the page list.
- `Sheet Content/*` product components live on Selected Screens instead of PRODUCT COMPONENTS.
- Stray instances: Badge on the Badges page (`104:162687`), Checkbox on Selected Screens (`102:6543`).
- Reference screens use two canvas sizes (onboarding 393×852, app 390×844). New work uses 390×844.
