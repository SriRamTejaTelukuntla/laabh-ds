## Icons
1,890 Lucide glyphs as components named `icon/<lucide-name>` on the Icons page (`1:6`): 24px, 2px stroke, colour bound to `icon/*` tokens.
Don't place them directly: use the [`Icon`](components/icon.md) wrapper (`Size` 10–32, swap `Glyph`), which sets the size and stroke. Every DS component uses it.

## Choosing between similar components
_Draft guidance, to be confirmed by the DS owner during Stage 2._

| Need | Use | Not |
|---|---|---|
| Pick 1 of 2–4 views on the same screen | Segmented Control | Tabs |
| Navigate between sibling content sections | Tabs | Segmented Control |
| Pick 1 of several rich options (with description) | Option Card (Control=Radio) | Radio |
| Pick 1 of a short plain list | Radio Group | Dropdown |
| Pick 1 of a long list | Dropdown | Radio Group |
| Instant setting | Switch / Switch Row | Checkbox |
| Agreement / multi-select | Checkbox | Switch |
| Header in a step-by-step flow | Top Bar | App Header |
| Header on main app tabs | App Header | Top Bar |
