# Spacing & Radius

Collection **Spacing & Radius Primitives** (single mode). Bind every padding, gap and corner radius to these.
Corner smoothing is **0.6** on every rounded shape (iOS squircle).

## Spacing in use
| Use | Token |
|---|---|
| Page side margin | `space/20` |
| Card padding | `space/20` (compact cards/rows `space/14`–`space/16`) |
| Between sections | `space/24` (after a hero `space/32`) |
| Section header inset from the card edge | `space/4` |
| Between stacked fields (form body gap) | `space/24` |
| Between Option Cards / list cards | `space/12` / `space/8` |
| Icon ↔ label in controls | `space/4`–`space/8` (built into components) |

## Radius in use
| Element | Token |
|---|---|
| Cards, Option Cards, Alerts | `radius/18` |
| Controls xs / sm / md / lg / xl | `radius/8` / `10` / `12` / `12` / `14` |
| Fields sm / md / lg (TextField, Dropdown) | `radius/10` / `12` / `14` · TextArea `radius/12` |
| Menus, tooltips | `radius/12` |
| Pills, chips, avatars, segmented, icon buttons | `radius/full` |
| Bottom sheet | `radius/40` (floating, 8px inset) |
