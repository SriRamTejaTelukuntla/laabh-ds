# Colors

Two collections: **Color Primitives** (164 raw values, never used directly in screens) and **Color Tokens**
(186 semantic tokens with `Light` and `Dark` modes). Always bind the semantic token. Values below are generated from `tokens/`.

## Pick by role

| Group | Use for | Key tokens |
|---|---|---|
| `surface/*` | Backgrounds of pages, cards, buttons, badges | `surface/page`, `surface/card`, `surface/raised` (menus), `surface/brand` (primary fills), `surface/<tone>-subtle` (tinted backgrounds), `surface/static-scrim` |
| `text/*` | All text | `text/primary` (default), `text/secondary` (supporting), `text/tertiary` (meta, non-essential), `text/brand` (links), `text/<tone>-strong` (titles on subtle tints), `text/static-white` (on solid fills) |
| `icon/*` | Icons | Mirrors `text/*`. Icons default to `icon/primary` |
| `border/*` | Strokes that carry meaning | `border/default`, `border/strong`, `border/focus`, `border/danger`, `border/gain`/`loss` (Dark-tinted outlines) |
| `glass/*` | The glass material: controls, fields, rows, nav, sheets | `glass/control`, `glass/field`, `glass/form` (sheet), `glass/edge` + `glass/hairline` (1px edges), `glass/track`/`thumb` (segmented) |
| `market/*` | Price movement **only** | `market/gain`, `market/loss`, `market/flat`, `*-subtle` |
| `data/*` | Charts and progress | `data/bar`, `data/track`, `data/fill`, series `data/violet`/`teal`/`pink`/`sky` |
| `atmosphere/*` | Screen backdrop behind content (used by `Screen Atmosphere`) | `atmosphere/grid`, `atmosphere/fade`, `atmosphere/spotlight` (Dark-only top glow), `atmosphere/spotlight-edge` (its fade-out stop) |
| `focus/ring` | Focus outlines | — |
| `elevation/*` | Shadow/highlight colours inside effect styles | Never bind directly; apply an `elevation/*` effect style ([elevation.md](elevation.md)) |

## Rules of thumb
- **Gain/loss** is always `market/*`, never `success`/`danger`, and always paired with a sign or arrow.
- `success` / `danger` buttons mean **Buy / Sell**. Danger elsewhere means failure or destruction.
- Text on a tinted surface uses the `-strong` text of the same tone (`surface/warning-subtle` → `text/warning-strong`).
- `static-*` tokens don't change between modes. Use them only on fills that don't change either (e.g. white text on `surface/brand`).
- Light is solid white with navy hairlines; Dark is glass (frost 4–14% fills). See [light-dark.md](light-dark.md).
