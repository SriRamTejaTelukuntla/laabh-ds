# Elevation

13 effect styles, one per surface role. Each binds its shadow, highlight and blur to `elevation/*` colour tokens,
so the **same style** is a soft black lift in Light and an inner-lit, deeper glass pane in Dark. Apply the style; never hand-roll a shadow.

## Which style goes with which surface

| Style | Pair with | Used by |
|---|---|---|
| `elevation/control` | `glass/control` · `glass/hairline` · `radius/12` | Glass buttons, fields, search, tab chips |
| `elevation/thumb` | `glass/thumb` · `radius/full` on `glass/track` | Segmented thumb, switch thumb |
| `elevation/tile` | `glass/control` · `glass/hairline` · `radius/12` | Market tiles (NIFTY 50) |
| `elevation/inset` | `glass/control` · `radius/12` **inside** a card | Inner controls in cards |
| `elevation/card` | `surface/card` · `glass/edge` · `radius/18` | Cards, Option Cards |
| `elevation/card-brand` | `surface/card` · `border/brand-soft` · `radius/18` | Hero card ("Your investments") |
| `elevation/logo` | `surface/static-white` · `glass/edge-strong` · `radius/12` | Company logo tiles |
| `elevation/primary-sm` | `surface/brand` · `radius/full` | Small brand buttons/chips |
| `elevation/primary` | `surface/brand` · `radius/12` | Primary CTA (Button lg/xl) |
| `elevation/overlay` | `surface/raised` · `glass/edge` · `radius/12` | Menus, tooltips |
| `elevation/nav` | `glass/nav` · `glass/edge` · `radius/full` | Floating nav / tab bar |
| `elevation/dock` | `glass/dock` · `glass/hairline` (top) · `radius/0` | Bottom action bar / dock |
| `elevation/sheet` | `glass/form` · `glass/edge` · `radius/40` | Bottom sheet (floating, 8px inset) |

## Rules
- **Inner cards get no shadow.** Only the outermost surface in a stack is elevated (use `elevation/inset` for controls inside cards).
- Keep effects subtle. Never stack two elevation styles or add custom glows.
