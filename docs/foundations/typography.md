# Typography

Families: **Inter** (UI text), **Space Grotesk** (all figures: `num-*` styles, plus the title styles `display-md/Semibold` and `display-xl/Semibold`), **JetBrains Mono** (documentation only: `mono/Regular`).
Sizes and line heights are variables in **Typography Tokens** with `Mobile` / `Tablet` / `Desktop` modes. Text styles bind to them,
so a frame's typography mode switches every style at once. Phone screens use **Mobile**.

## Rules
- Use text styles only: `<role>/<Weight>`; for numbers `num-<role>/<Weight>` (Regular, Medium, Bold; no Semibold).
- Even sizes with a minimum of 11. `caps-sm` (10) is the only exception, for dense data badges. Round **down** between steps.
- `caps-*` = uppercase + 8% tracking for overlines/labels. Display roles use −1 to −2% tracking.
- Full guidance (which role for what) is in `.claude/rules/typography.md`.

## Common pairings (from the reference screens)
| Element | Style |
|---|---|
| Screen title | `display-md/Semibold` (renders Space Grotesk Bold) |
| Hero amount (portfolio value) | `num-display-2xl/Medium` or `num-display-xl/Medium` |
| Card title | `label-lg/Semibold` |
| Section overline | `caps-md/Semibold` in `text/secondary` |
| List row title / subtitle | `body-lg/Medium` / `body-sm/Regular` in `text/secondary` |
| Price in a row / change | `num-body-lg/Medium` / `num-body-sm/Medium` in `market/*` |
| Field label / helper | `body-sm/Medium` / `body-sm/Regular` |
