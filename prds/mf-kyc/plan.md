# MF KYC: screen plan

> **Status:** reviewed: changes required (2 S1, 3 S2) · **Updated:** 2026-10-21 · **Branch:** `prd/mf-kyc` · **Figma file:** [Laabh — MF KYC](https://www.figma.com/design/kwRnjJU3KdW28Wi7gSU0mG) (page `Screens` `0:1`)

Scope (proposed): **Journey A, MF-only account (Phase 1, release R1)**: shared steps S1–S7, then A8–A11. Journeys B (full account) and C (upgrade) are Phase 2 and not in this plan unless Q1 says otherwise.

## Flows
1. **Contact (S1–S2):** welcome → mobile number (linked to the bank account) → mobile OTP, auto-verifies on the 4th digit, with the optional credit-bureau consent checkbox (details in a sheet) → set MPIN → confirm MPIN → email via Google/Apple (primary) or another email + OTP (auto-verifies).
2. **Identity (S3–S5):** PAN shown as a PAN card (bureau hit) or typed (miss) → confirm; button loads while PAN and KRA are checked (no checking screen) → KRA Validated → Bank · KRA not verified → DigiLocker (placeholder) → Bank · invalid PAN → blocked · offline → retry · name mismatch / under process / unfixable hold → to be discussed.
3. **Bank (S7):** bank account fetched from the mobile number → confirm (single holder) · or add another account (UPI ₹1 or account number + IFSC, also used to add a bank later) → failures as before.
4. **Profile (S6):** personal details (no gender/marital default, verified address, optional communication address) → work, income, place of birth, nominee switch and one citizen/tax/PEP declaration → nominees (one-tap fix when shares ≠ 100%).
5. **Review & eSign (A8–A9): to be discussed.** Review, nominee OTP and eSign screens are parked in section 5.
6. **Submit & invest (A10–A11):** after eSign the user lands on Start investing: set up autopay (UPI Autopay / eNACH), start a SIP from ₹100 from popular funds or search → review → autopay → SIP scheduled (first debit after the account is active). Track status → Submitted timeline.
